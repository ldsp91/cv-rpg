# cv-rpg

To install dependencies:

```bash
bun install
```

To run the dev server (Bun.serve + HMR):

```bash
bun run dev
```

To build the static site into `dist/`:

```bash
bun run build
```

To run the tests:

```bash
bun test
```

Built with [Bun](https://bun.com). See `docs/STACK.md` for the chosen stack and `docs/VISION.md` for what this is.
