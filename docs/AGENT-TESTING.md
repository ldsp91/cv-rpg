## State reset

- There is no server-side state: no database, no file writes, no session store (verified: no persistence layer in the code). To get back to a clean state, kill the dev server and restart it; the app is always served fresh from the checked-out files.

## Gotchas

- `bun install` exits with an error on the `quartermaster` devDependency in any environment without `/Users/levent/agents/quartermaster-cli`. App dependencies are installed anyway — do not treat the non-zero exit as a build failure. (verified in this run)
- `index.ts` sets no port; the server binds 3000 by framework default. Anything else already listening on :3000 will block the dev server from starting. (verified: :3000 was free and the server bound it)
- The split is structural, per ADR-0003: Phaser owns `#game` (booted once), React owns `#ui`. Automated tests must not re-render or replace `#game`; the canvas only exists after the page's JS has run. (verified in this run: `#game canvas` present, `#ui` holds the React overlay)
- `data/career.json` is statically imported (inlined into the bundle) — editing it requires the dev server to be running with HMR, or a page reload, to take effect. (inferred from `docs/STACK.md` and `career.test.ts` importing the file)
