# Prototype #3 — the coding-puzzle mechanic

Ticket: https://github.com/ldsp91/cv-rpg/issues/3

Open `index.html` (double-click; no build, no server). Three variants of v1's one
coding-puzzle Challenge, switchable via `?variant=A|B|C` (or ←/→):

- **A** — click the broken line
- **B** — pick the fix
- **C** — fill in the blank

**Winner: C (fill in the blank)** — the owner's decision, recorded on ticket #3's
resolution. The full set (winner and losers alike) stays here as reference material;
the winning design is rewritten properly for the overlay when the implementation
happens, never promoted as-is.
